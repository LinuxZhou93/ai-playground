## 📊 具体图表数据关联

### **C1: 学习进度水球图**

```
数据源:
  completionRate = (completedLessons / totalLessons) * 100

触发更新:
  - markAsCompleted()
  - completeQuiz()

计算逻辑:
  const completed = lessons.filter(l => l.completed).length;
  const total = lessons.length;
  const rate = (completed / total) * 100;

ECharts更新:
  chart1.setOption({
    series: [{ data: [rate / 100] }]
  });
```

### **C3: 成绩趋势折线图**

```
数据源:
  quizScores = lessons
    .filter(l => l.type === 'quiz')
    .map(l => ({ date: l.completedAt, score: l.score }))

触发更新:
  - submitQuiz()
  - completeQuiz()

计算逻辑:
  const scores = quizLessons.map(l => l.score);
  const dates = quizLessons.map(l => formatDate(l.completedAt));

ECharts更新:
  chart3.setOption({
    xAxis: { data: dates },
    series: [{ data: scores }]
  });
```

### **C7: 学习热力图**

```
数据源:
  calendarData = lessons
    .filter(l => l.completed)
    .reduce((acc, l) => {
      const date = toDateString(l.completedAt);
      acc[date] = (acc[date] || 0) + 1;
      return acc;
    }, {})

触发更新:
  - markAsCompleted()
  - 每日学习结束

渲染逻辑:
  Object.entries(calendarData).forEach(([date, count]) => {
    const cell = document.querySelector(`[data-date="${date}"]`);
    cell.style.background = `rgba(0, 240, 255, ${count / 5})`;
    cell.textContent = count;
  });
```

### **C16: 成就徽章墙**

```
数据源:
  badges = checkBadgeRules(learningData)

徽章规则:
  {
    'first_lesson': completedLessons >= 1,
    'module_master': completionRate === 100,
    'perfect_score': lessons.some(l => l.score === 100),
    'note_taker': totalNoteWords >= 1000,
    'ai_explorer': aiQuestionsAsked >= 10,
    'streak_7': consecutiveDays >= 7
  }

触发更新:
  - 任何学习行为完成后
  - 检查所有规则
  - 解锁新徽章时播放动画

渲染逻辑:
  badges.forEach(badge => {
    const element = document.querySelector(`#badge-${badge.id}`);
    element.classList.remove('locked');
    element.classList.add('unlocked');
    playUnlockAnimation(element);
  });
```
