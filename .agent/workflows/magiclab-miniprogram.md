---
description: 顶级微信小程序开发工作流 (Hybrid 架构)
---

本工作流用于快速构建、部署并发布具备“顶级”体验的微信小程序。采用 H5 Web-view + Next.js + Supabase 的混合架构，兼顾开发效率与原生体验。

### 第一阶段：需求拆解与架构设计
1. **定义目标**：描述业务场景（如：营地评估、课程管理、电商展示）。
2. **视觉风格确认**：确定配色方案（推荐：深色模式、玻璃拟态、渐变动效）。
3. **数据建模**：在 Supabase 中定义核心表结构并开启 RLS 安全策略。
4. **路由规划**：在 `middleware.ts` 中配置域名重写逻辑（如：将 `ai.zhouxiaomai.com` 映射到特定子目录）。

### 第二阶段：环境初始化
// turbo
1. **小程序端**：在 `miniprogram/` 下初始化项目，配置 `app.json` 和 `project.config.json`（设定正式 AppID）。
2. **云端部署**：确保 GitHub 仓库已配置 Vercel 自动部署，并绑定自定义生产域名。

### 第三阶段：全自动视觉开发 (核心)
1. **基础组件库**：在 `public/` 下创建独立的 H5 目录（如 `frontend/`），编写极致美观的 HTML/CSS。
2. **动态逻辑**：集成 Supabase JS SDK，实现数据的实时增删改查。
3. **移动端适配**：
   - 使用 `viewport` 适配不同机型。
   - 移除所有 `target="_blank"` 链接（防止 web-view 弹出浏览器）。
   - 全部跳转使用基于生产域名的**绝对路径**。

### 第四阶段：专业功能增强
1. **报告与导出**：
   - 编写 `@media print` 样式实现 A4 比例的 PDF 打印。
   - 移除调试用的 `alert`，替换为现代化的 Toast 或 Modal。
2. **多态适配**：针对微信 iOS 和 Android 的 web-view 渲染差异进行微调。

### 第五阶段：发布与审核
1. **域名校验**：获取微信校验文件（如 `xxx.txt`），放置在 `public/` 根目录。
2. **后台配置**：在微信公众平台配置**业务域名**（Business Domain）。
3. **提交审核**：
   - 编写专业的版本描述与测试备注。
   - 上传代码并等待审核。
