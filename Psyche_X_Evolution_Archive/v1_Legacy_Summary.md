# Psyche-X Legacy Architecture Summary (v1.0)
**Date:** 2025-12-10 (Pre-Evolution)
**Status:** Archived / Replaced by v2.0 Evolution Protocol

## Overview
The legacy version of Psyche-X was designed as a "World-Class" overhaul of a cognitive assessment platform, focusing on high-end visuals and "Glassmorphism 3.0" aesthetics. While the core files are currently inaccessible due to filesystem constraints (Error: `bad CPU type`), the following architecture is reconstructed from system manifests.

## Core Architecture
- **Framework**: Vanilla JS + Three.js + GSAP
- **State Management**: `engine_core.js` (Precursor to the current `kernel.js`)
- **Visuals**: Heavy use of `Vanilla-Tilt` for 3D card effects and `Chart.js` for data visualization.

## Modules (v1.0)
### 1. The Portal (`portal.html`)
- **Concept**: Cinematic 3D entry.
- **Features**: 
    - Fullscreen 3D particle background.
    - "Enter the Void" interaction model.

### 2. The Hub (`hub.html`)
- **Design Language**: Glassmorphism 3.0.
- **Key Elements**:
    - Ambient 3D backgrounds.
    - Tilt-enabled task cards.
    - Advanced filtering system for cognitive tasks.

### 3. The Runner (`runner.html`)
- **Logic**: Replaced simple game loops with `engine_core` driven mechanics.
- **Objective**: High-speed visual processing and reaction time training.
