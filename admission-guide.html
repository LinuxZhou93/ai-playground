DEEP DIVE // 项目班录取细节

打破信息差，看透名校招生逻辑

PROTOCOL 01

录取权重分布

• 全国一等奖：通常直接获得优先调档资格。
• 调档分构成：中考成绩 (50%) + 专业测试 (50%)。
• 隐形成绩：校级面试中的逻辑表达能力往往是决定性因素。

PROTOCOL 02

专业测试考什么

• 编程：C++ 基础语法与核心算法 (DFS/BFS/动态规划)。
• 机器人：工程设计笔记、机械结构稳定性分析。
• 创新：对社会问题的科技解决方案演说。

PROTOCOL 03

自主选拔避坑指导

• 错峰报名：避免扎堆三校七区，关注处于上升期的重点高中。
• 奖项效力：2024年起，部分非白名单竞赛效力减弱，务必精准对标。

PARENT Q&A // 家长核心关注

针对成都升学政策的常见疑难解答

Q1: 科技特长生在中考中能加分吗？

A: 目前成都中考已取消直接加分，改为“项目班”录取。科技特长生的优势体现在优先进入名校的“科技创新班”，实现低分调档或专项录取。

Q2: 哪些竞赛在成都升学中含金量最高？

A: 重点关注“教育部白名单”竞赛。如 NOI (信息学奥赛)、中国青少年机器人竞赛、全国青少年科技创新大赛。省级以上一等奖是进入顶级项目班的“敲门砖”。

Q3: 如果孩子没有竞赛奖项，还能走科技特长吗？

A: 可以通过学校的自主招生（校考）突围。部分学校会考查孩子的逻辑思维、基础编程和实验动手能力。建议提前准备个人作品集（Portfolio）。
