LEARNING PATH // 进阶路线图

STAGE 1: 编程启蒙与Python基础

万丈高楼平地起。学习AI的第一步是掌握计算机语言。Python是AI领域的通用语言，我们将从趣味编程开始，打下坚实基础。

Scratch Python Syntax Logic Algorithms

STAGE 2: 数据科学与可视化

AI的燃料是数据。在这个阶段，我们将学习如何处理、分析数据，并使用图表让数据“说话”，探索数据背后的秘密。

Pandas Matplotlib Data Analysis Visualization

STAGE 3: 机器学习初探

教会机器像人一样思考。学习经典的机器学习算法，从分类到回归，亲手构建能够预测未来的智能模型。

Scikit-learn Regression Classification K-Means

STAGE 4: 深度学习与神经网络

深入大脑的奥秘。构建神经网络，模仿人脑神经元连接，挑战图像识别、自然语言处理等高阶任务。

TensorFlow PyTorch Neural Networks Computer Vision

STAGE 5: 生成式AI与大模型

站在巨人的肩膀上。探索ChatGPT、Midjourney等前沿技术，学习Prompt Engineering，甚至微调属于你自己的大模型。

LLMs Transformers Prompt Engineering Fine-tuning
