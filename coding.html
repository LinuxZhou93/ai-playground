Common Questions

常见问题解答

学习这个平台需要付费吗？ +

完全免费！所有 Scratch 编辑器、基础课程和项目案例库对所有学生开放。虽然部分高级 AI 功能可能需要积分，但核心编程体验始终免费。

我需要下载安装软件吗？ +

不需要。CodingLab 是纯 Web 端平台，打开浏览器即可开始编程。支持 Chrome, Edge, Safari 等主流浏览器。

支持 iPad 或平板电脑吗？ +

支持！特别是 ScratchJr 编辑器针对触摸屏进行了优化，非常适合在 iPad 上使用。Scratch 3.0 也完全兼容平板操作。
