# XMP 本地版本完成度审计

审计日期：2026-07-28
审计范围：`app/xmp` 本地产品演示、FutureClass 复用证据、自动化浏览器验收、构建边界与云端发布状态。

## 结论

XMP 十三大产品模块、统一角色壳、12 分钟 Demo Room、产品/融资底稿和本地演示手册已经形成一套可运行、可点击、可重复验收的高保真本地产品。产品主轴已明确回到教学数字化：AI 提升教师备课、授课、观察和复盘效率，多设备共同服务老师的一节课。

XMP 专属类型构建与 21 条浏览器测试可以独立通过。系统已具备 FutureClass 只读聚合适配层、数据源状态中心、安全回退机制，以及贯穿调度、AI 教学、课堂、成长、家园、设备和访问控制的本地优先事件总线。AI 教学驾驶舱把签名课程、教学调度、摄像头、拾音阵列、大屏、边缘中枢、奇妙宠、匿名小组学情和教师复盘放进一节课：AI 生成教师可编辑教学包，五项就绪后由教师启动，建议只能由教师采用或忽略，关键设备异常会关闭 AI，课后事实必须由教师确认签发。标准生产构建已通过，生产产物启动后的 21 条 XMP 浏览器测试也全部通过。

## 自动化门禁

### XMP 类型构建

```bash
pnpm check:xmp
```

覆盖：

- `app/xmp`、`app/api/xmp` 与 `lib/xmp` 全部 TypeScript/TSX。
- 独立 `tsconfig.xmp.json`，不被旧仓库其他模块的历史错误污染。

格式与差异检查在每个模块提交前按变更文件执行；旧仓库仍有少量历史文件未采用当前 Prettier 输出，因此不把全目录格式检查伪装成绿色门禁。

### XMP 浏览器测试

先启动本地服务：

```bash
pnpm dev
```

再运行：

```bash
pnpm test:xmp:e2e
```

测试默认复用本机 Chrome，避免在磁盘空间紧张时重复下载 Chromium。测试覆盖十三个路由、AI 备课到教师签发的完整课堂流程、智慧学情到下一课草稿、快照 API、事件 API 默认零外发、调度冲突到课堂签名交付、课堂到成长审核的跨路由事件持久化、高风险权限双人审批与撤销、直接路由拒绝，以及关键心跳丢失、跨模块恢复和人工接管显式释放，并完整走完 Demo Room 六幕。

### 事件安全契约测试

```bash
pnpm test:xmp:unit
```

53 条契约与状态机用例验证事件隐私边界、AI 备课、课堂五项就绪、教师决定 AI 建议、匿名事实证据、关键设备暂停、教师接管、课后签发、可信课堂命令、课程发布、教学调度、权限默认拒绝、作用域、双人审批、撤销、会话轮换、终态约束和损坏快照拒绝。

### 全仓生产构建

```bash
pnpm build
```

无 Supabase 环境变量时，构建会明确进入惰性本地客户端模式：预渲染允许返回空数据，但卡密、用户资料和 Stripe Webhook 等写服务会返回 `503`，不会连接默认远端或伪造生产凭据。

构建仍报告 `unpdf`/PDF.js 动态依赖警告，但不影响编译、84 个静态页面生成、构建追踪或退出状态。该警告应在正式发布前作为供应链优化项处理，不应误报为构建失败。

## 生产化未完成项

这些项目不应被融资演示掩盖：

- XMP 已能通过显式配置读取 FutureClass ERP、课程资产与成长档案的园所级聚合数量；当前本机没有启用真实连接，也没有任何写能力。
- 课堂、成长、家园和设备动作默认写入浏览器本地事件流；服务端追加式表、幂等 API、事件级 RLS 和 Outbox 已形成可迁移代码，但尚未在试点 Supabase 执行或用真实园所 JWT 验证。
- 本地课堂会话协议已经运行；真实教师认证、设备证书、园所边缘代理、自动心跳超时调度、消息送达和删除编排器尚未接通。
- 本地课程发布协议已经运行；真实生成任务、数据库版本库、不可变对象存储、正式签名密钥和多园区发布审批尚未接通。
- 本地教学调度协议已经运行；真实请假与师资资格、空间容量、设备证书与在线状态、物料库存、ERP 写入、并发锁和正式计划签名尚未接通。
- 本地 AI 教学协议已经运行；真实视觉算法、摄像头/拾音数据流、边缘代理、设备证书、模型校准、误报处置、硬件在环与教师前后测尚未接通。
- 本地访问控制协议已经运行；真实 Auth/JWT、MFA、设备证明、员工生命周期、服务端统一鉴权、全业务表 RLS 验证和 break-glass 流程尚未接通。
- 数据影响评估、第三方处理协议和正式法律审查未完成。
- `unpdf` 仍有动态依赖构建警告；真实 PDF 解析链路需在目标部署运行时单独验证。
- 本机磁盘空间紧张；本次首次生产构建曾因 `ENOSPC` 中断，清理 1.5 GiB 可再生成的 pnpm 缓存后重跑成功。后续构建仍应先检查空间并在验收后清理 `.next`。

## 发布结论

当前版本适合本地产品演示、客户共创、团队评审和融资尽调准备；不适合直接连接真实儿童数据或发布生产环境。任何云端部署仍需用户再次明确确认，并通过发布前门禁。
