# XMP 本地演示与验收手册

## 运行边界

- 仅在本地运行：`http://127.0.0.1:3000/xmp`
- 不使用真实儿童、家长、教师或财务数据。
- 不推送代码、不部署云端、不连接生产 Supabase。
- 页面状态均为浏览器内演示状态，刷新页面可恢复初始状态。

## 启动

```bash
cd "/Users/zhoulin/Documents/Swarm 工作/ai-playground-voice-fix"
pnpm dev
```

打开：`http://127.0.0.1:3000/xmp`

如需释放磁盘空间，可停止开发服务器并删除可再生的 `.next` 缓存；源码、提交和依赖不会受影响。

## 12 分钟融资级演示路线

在系统总控台点击“启动 12 分钟完整演示”。使用左右箭头切换六幕，点击每幕的模块按钮进入真实产品页面。

| 时间        | 演示幕   | 页面                                | 必须证明的动作                                     |
| ----------- | -------- | ----------------------------------- | -------------------------------------------------- |
| 00:00–01:30 | 系统机会 | `/xmp`                              | 展示十大模块、角色模型、教学闭环和行动信号         |
| 01:30–03:30 | 内容供给 | `/xmp/curriculum`                   | 对比 v3.3 差异，依次送审、批准、签名发布并课前锁版 |
| 03:30–06:00 | 现场交付 | `/xmp/scheduling`、`/xmp/classroom` | 清理排课冲突、确认就绪、签名发布并启动课堂         |
| 06:00–08:00 | 数据复利 | `/xmp/growth`、`/xmp/family`        | 审核成长证据、签发报告、接受家庭任务并反馈         |
| 08:00–10:00 | 规模复制 | `/xmp/operations`、`/xmp/fleet`     | 推进交付里程碑、审批流水、设备诊断与事件关闭       |
| 10:00–12:00 | 信任门槛 | `/xmp/governance`                   | 撤回授权、处理删除、关闭安全事件、生成证据包       |

## 十大模块入口

| 模块         | URL               | 核心验收                                   |
| ------------ | ----------------- | ------------------------------------------ |
| 系统总控台   | `/xmp`            | 角色切换、课堂筛选、Demo Room              |
| AI 课程工厂  | `/xmp/curriculum` | 版本差异、职责分离、门禁、签名发布、回滚   |
| 教学调度     | `/xmp/scheduling` | 三类资源冲突、五项就绪、代课、签名与回滚   |
| 实时课堂     | `/xmp/classroom`  | 签名锁版、节奏推进、建议处理、安全控制     |
| 奇妙宠       | `/xmp/companion`  | 儿童选择、语音状态、静音、成人接管         |
| 成长智能     | `/xmp/growth`     | 证据审核、编辑、报告生成与签发             |
| 家园共育     | `/xmp/family`     | 内容视图、家庭任务、提交反馈、教师回复     |
| 设备与边缘云 | `/xmp/fleet`      | 诊断、重启确认、事件处理、灰度发布         |
| 园所运营     | `/xmp/operations` | 经营/交付/资源视图、审批、里程碑和工单     |
| 数据治理     | `/xmp/governance` | 数据地图、授权撤回、权利请求、事件与证据包 |

## 演示纪律

1. 所有数字先说明是演示口径。
2. 不宣称已经获得监管认证或第三方安全认证。
3. 不把本地交互原型描述成生产数据已经接通。
4. 不承诺未被合同、财务和客户证据支持的收入、增长、客单价或市场份额。
5. 讲 AI 时始终同时讲教师责任、儿童安全和数据边界。

## 发布前门禁

云端部署必须由用户再次明确确认。确认前至少完成：

- 生产租户与真实身份权限设计。
- 数据处理清单与个人信息保护影响评估。
- FutureClass 读写适配层和迁移回滚方案。
- 边缘设备身份、签名发布和离线容错验证。
- 真实园所试点、SLA、备份恢复和应急演练。
- 安全测试、依赖审计、监控告警与正式域名配置。
