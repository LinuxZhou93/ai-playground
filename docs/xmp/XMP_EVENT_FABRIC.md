# XMP 教学闭环事件总线

## 产品目的

XMP 的课堂、成长、家园和设备能力不能只是四个并列页面。事件总线用同一个 `correlationId` 把一次课堂中的教学动作、候选证据、教师审核、家庭送达和设备保障连接成可追溯闭环。

当前默认只在浏览器本地运行，用于验证产品行为和跨模块协作，不写入 Supabase，也不控制真实设备。同时已经提供一套默认关闭的服务端迁移层：追加式表结构、租户 RLS、受保护事件 API、幂等写入与浏览器离线 Outbox。只有显式启用并完成园所鉴权后才会同步。

## 事件结构

每条事件包含唯一事件 ID、课堂关联 ID、事件类型、业务域、事实摘要、操作者、业务对象、发生时间、隐私级别和事件来源。

事件不包含儿童姓名、联系电话、监护关系、原始音频、视频或照片。

## 已接入动作

| 模块     | 当前产生的事件                           |
| -------- | ---------------------------------------- |
| 实时课堂 | 开始、恢复、暂停、课堂调整、匿名证据候选 |
| 成长智能 | 教师确认入档、教师驳回                   |
| 家园共育 | 教师签名发布、家庭事实转候选、反馈不采纳 |
| 设备舰队 | 设备降级种子事件、安全诊断完成、受控恢复 |

## 本地优先与离线 Outbox

事件保存在浏览器 `localStorage` 的 `xmp-local-event-stream-v1`，最多保留 80 条。页面跳转后仍可在顶部“事件链”入口查看。点击“重置演示”恢复五条标准闭环事件。

默认 `XMP_EVENT_MODE` 为空，因此状态探针返回 `local-only`，所有互动只落本地，不产生网络写入。显式设置 `XMP_EVENT_MODE=futureclass-server`，并提供 Supabase 服务端地址、service-role 与 `XMP_TENANT_ID` 后，系统还会要求有效的加密园所会话。通过鉴权后，本地新增事件进入 Outbox，按事件 UUID 作为幂等键逐条追加；断网或服务异常会保留失败状态，教师可在事件中心重试。

## 服务端迁移层

`database/xmp_event_fabric.sql` 定义了：

1. `xmp_events` 追加式事件表，以及事件类型、业务域、字段长度和载荷版本约束。
2. `(tenant_id, idempotency_key)` 唯一约束，避免离线重试造成重复事件。
3. 园所关联 ID、接收时间和到期时间索引。
4. 匿名 30 天、聚合 90 天、教师审核 180 天的分级留存时间。
5. 只允许匹配 JWT 园所声明的登录用户直读；匿名与登录用户均无直写权限。
6. 禁止历史事件更新；过期删除只能由 service-role 调用受限函数。

`/api/xmp/events` 是唯一浏览器写入口。租户 ID 只从服务端环境注入，客户端不能提交；请求体使用严格字段白名单、16 KiB 上限、枚举和业务域一致性校验。课程、调度、AI 教学、课堂、成长、家庭、设备与访问控制通过七个运行事件域共用这一边界。API 不接收儿童身份、电话、监护关系或原始媒体字段，也不会把数据库错误明细返回浏览器。

数据库脚本目前只保存在仓库中，未执行。开启服务器模式前仍需完成：

1. 在目标 Supabase 项目评审并执行迁移，验证 JWT 中的 `campus_id` 声明。
2. 将操作者标签替换为服务端会话派生的可信主体 ID 与显示投影。
3. 增加速率限制、批量补传、死信告警和设备身份认证。
4. 建立事件导出、法律保留、数据主体删除与审计审批编排。
5. 完成家庭消息、设备遥测与成长档案之间的最小权限投影。

## 验收证据

`tests/e2e/xmp-system.spec.ts` 会验证默认状态为零外发、服务端 POST 返回 `LOCAL_ONLY`，然后在实时课堂产生开始和候选证据事件，跳转到成长智能完成教师审核，再验证这些动作仍出现在同一关联事件链中。
