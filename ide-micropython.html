什么是 MicroPython?

它是 Python 3 的精简高效实现，专为微控制器设计。它包含 Python 标准库的一小部分，并经过优化以在受限环境中运行。

WebREPL & WebUSB

现代浏览器支持直接通过 USB 与开发板通信。点击左侧的 "Connect Device" 即可尝试连接您的 ESP32 或 Raspberry Pi Pico 开发板。
