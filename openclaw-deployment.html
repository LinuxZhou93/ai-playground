CHAPTER 01:
HIGH AVAILABILITY (HA)

单点故障是极客的大忌。成电小创老师的部署方案天生具备“动态扩展性”。

LB & REPLICAS

通过 Nginx-Claw 负载均衡器，我们可以同时驱动 3 个以上的 OpenClaw 实例。当一个实例在复杂的 Python 渲染中耗尽内存时，流量会瞬间被切流到其它空闲节点，确保你的创作从未中断。

HEALTH-CHECK SIDEKICK

我们集成了一个轻量级的监控哨兵（Watchdog）。它每隔 5 秒会向核心引擎发送一个‘心跳’脉冲。如果检测到引擎卡死，它会通过 Docker API 直接触发重启。这是一种不需要运维的‘自愈式’云原生架构。

# 启动自愈式集群...
$ docker-compose up --scale agent=3 -d
> [INFO] Deploying 3 Replicas (HA_MODE_ON)...
> [INFO] Scaling complete. Global Bus synchronized.

CHAPTER 02:
INFRASTRUCTURE AS CODE

手工配置？那太 2020 了！在成电小创老师的实验室，一切都是代码定义的。

"无论是 Terraform 定义的 VPC，还是 Docker 定义的 Runtime，我们的目标是让实验室在全世界任何一个地方都能在 5 分钟内‘一键降临’。"

SECRET HARDENING

所有的 API Keys 都被 **SOPS (Secrets OPerationS)** 加密存储。即便是你的 Git 仓库被意外公开，攻击者也无法解密出你的贵重 Token。这就是极客的安全法则。

// Terraform VPC
resource "aws_vpc" "claw" {
  cidr_block = "10.0.0.0/16"
}
// SOPS Secrets
ENC[AES256_GCM,data:Y2U...]
api_key: "K-42"
// Cloudflare Tunnel
ingress:
  - hostname: claw.me
ZAP!
