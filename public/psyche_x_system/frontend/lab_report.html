板块一：基础机械结构技能指标

PAGE 02 / 06

本学期机械结构课程核心教学标准参考国际经典工程教育框架（不包含任何特定乐高商标字眼）。评估重点在于孩子对于物理机械结构的拆解、力学省力原理的实操分析，以及对复杂传动装置的空间建构力。

01

简单机械核心原理

杠杆原理、轮轴结构、斜面省力机制

掌握良好

学员已深入理解杠杆的三要素（支点、动力点、阻力点），能够独立组装并调整不同类型的省力杠杆与平衡秤结构。在轮轴应用中，能够合理识别方向控制与力矩输出的增益，掌握稳固的工程学地基。

02

复杂机械传动应用

齿轮变速系统、滑轮组、连杆与棘轮传动

熟练掌握

学员掌握了齿轮平行咬合及垂直齿轮传动的特性。能根据需求自主设计多级加速或减速齿轮传动组。在滑轮组搭建中体现出清晰的省力与改变力的方向意识，能够应用棘轮实现防逆转的安全棘爪机构。

03

工程空间结构建构

三角形稳固性、承重桥梁、机身底盘刚度

持续精进

学员能较好地在物理作品中加入三角形支撑架构以增强抗拉强度，避免运行过程发生偏摆。对轴套防脱滑、螺栓紧固力学具备良好的感知，拼装速度快捷，结构件排布严密合理。

板块二：基础算法与电子控制指标

PAGE 03 / 06

本板块关注孩子在图形化逻辑流程上的构建逻辑，以及软硬件物理闭环调试能力。重点包含对事件驱动程序、条件判断流、红外与物理传感器输入参数的闭环控制。

CODE
04

流程控制与算法逻辑

顺序结构、循环嵌套、多条件选择分支

表现优异

学员具备极强的前推式算法逻辑。在进行循迹或避障算法的图形化设计时，能快速理解“当...满足时，执行A；否则执行B”的分支判定。可以丝滑使用无限循环及计数循环，降低程序控制冗余。

CTRL
05

物理传感器输入与电子交互

红外距离传感器、倾斜检测、电机参数调速

熟练掌握

能够独立将倾斜传感器和测距传感器的实时返回数值作为算法变量引入。熟练掌握电机的启动、反转以及基于占空比的功率调节。理解模拟信号与数字信号的基本差异，实现了精准的闭环反馈控制。

DEBUG
06

系统级硬件调试与排错 (Debug)

端口映射排障、逻辑死循环排查

持续精进

在硬件与程序通信发生故障时，表现出了清晰的归因排错方法。能够分段检测“供电通路——端口接线——软件指令”，极具敏锐的故障排查意识，极少出现因硬件未上电而怀疑程序出错的常识性漏洞。

八维素质维度释义

科学逻辑: 对算法流及电子输入/输出因果关系的理解深度。
逆商抗挫: 面对结构松坍塌或算法Bug时主动自我调节能力。
情绪与收纳: 科创箱组件规整度及心态稳定情况。
社交融入: 主动阐述设计思路并融入科创集体的情感表现。
创新想象: 对课件范式结构的延伸设计与新颖硬件改造。
协作沟通: 与小组成员任务合理分工协作及思想反馈表达。
