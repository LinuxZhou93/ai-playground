# L07：逻辑中枢：ESP32 联调

## 课程信息
- **所属模块**：M3 智力注入 — 开源硬件与电路主控
- **课时**：90 分钟
- **教学目标**：
  1. 记忆（Remember）：认识 ESP32-S3 开发板及 GPIO 引脚分布图。
  2. 理解（Understand）：理解微控制器如何通过数字电平输出来控制物理元件。
  3. 应用（Apply）：搭建 Arduino IDE 编译环境，编写并上传控制板板载 LED 闪烁的 Blink 程序。
- **核心素养对标**：工程思维

## 教学流程

### 一、导入环节（10 分钟）
**情境导入**：教师展示一辆无法自己躲避障碍的遥控车，和一辆有大脑（主控芯片）可以自动规划路线的智能寻迹车。
**问题驱动**：在前面的模块里，我们有了感知形变的"神经末梢"（碳膜）和包裹它的"骨骼皮革"（3D外壳），但它们是个死物。如何向里面注入灵魂中枢（MCU）？
**师生活动**：
- 老师：发放芯片，科普 MCU（微控制器单元）概念和它的主频算力。
- 学生：观察 ESP32-S3 开发板，找到各种电子元器件（天线、USB接口、排针）。

### 二、核心探究（50 分钟）
**材料清单**：
- ESP32-S3 开发板
- Type-C 数据收发线（注意甄别不是纯充电线）
- 电脑（安装好 Arduino IDE 及芯片驱动）
- 杜邦线，LED 灯珠，220Ω 面包板电阻

**操作步骤**：
1. **环境配置（15 分钟）**：师生共同在 Arduino IDE 中选择对应的开发板型号（ESP32S3 Dev Module），并选择正确的 COM（Windows）或 /dev/cu.usbserial（Mac）端口号。
2. **点亮第一盏灯（15 分钟）**：使用经典的"Hello World" — Blink 程序代码。讲解 `setup()` （只运行一次的初始化）和 `loop()` （无限循环）函数结构。通过 `digitalWrite(HIGH/LOW)` 控制板载灯明暗。
3. **拓展物理接口（20 分钟）**：认识 GPIO（通用输入输出引脚）。用杜邦线将一颗外置的 LED 按极性接到面包板上（串联降压电阻）。更改代码中绑定的引脚号（如改到 GPIO 2），控制外部 LED 闪烁。

**预期数据**：
代码编译无报错，上传进度条达到 100%。板载灯或外部串联的红色 LED 以精确设定的频率（如亮 0.5 秒，灭 0.5 秒）周期性跳动。

**安全提示**：
连接外置 LED 必须串联电阻，否则会导致电流过大烧毁引脚或灯珠；插拔杜邦线时要尽量断电。

### 三、总结与反思（15 分钟）
**师生活动**：
- **学生展示**：展示自己用代码创造出的独特闪烁节奏（如 SOS 摩斯密码灯效）。
- **教师点评**：揭示数字引脚的本质：在 0V 和 3.3V 极速切换电平。通过高低电平，代码指令变成了物理世界真实的电压输出。
- **知识建构**：如果能发数字信号控制灯，那接上 MOS 管放大电流，是否就可以控制碳膜的微秒级加热开关了？

### 四、拓展挑战（15 分钟）
**串口监视器探针**：利用 `Serial.begin(115200);` 和 `Serial.println("Hello ESP32");` 命令，让主控板不仅能自己干活，还能通过数据线用文本跟电脑"对话"汇报情况。

## 评价标准
| 维度 | 优秀(A) | 良好(B) | 合格(C) |
|:---|:---|:---|:---|
| 环境驱动 | 独立自主排查端口识别不出等常见驱动问题，熟练烧录 | 按步骤顺利选定环境并烧入 | 在同学或老师排错指导下完成烧录 |
| 语法理解 | 清楚明白 `setup` / `loop` 工作机制并尝试魔改参数 | 能够对照参考代码无死角盲敲 | 直接复制粘贴代码未仔细阅读 |
| 物理连线 | 熟练使用面包板导流槽实现外围元器件扩展并测算限流电阻 | 能够在老师指引下插对正负极引脚 | 盲目跟插，出现 LED 烧毁情况 |

- **所需软件**：Arduino IDE v2.x、串口驱动程序
