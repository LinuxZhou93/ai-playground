OBJECTIVES

核心素养与通关要求

  • 理解（Understand）：理解人体工学设计的基本考量，以及数字孪生中的 CAD 建模概念。
  • 2. 应用（Apply）：熟练掌握 Fusion 360 基础功能（草图绘制、拉伸、倒角、壳化）。
  • 3. 创造（Create）：设计 CarbonBox v1.0 原型机的基础外部形态外壳。

THE HOOK

情境导入

情境再现：对比初代移动电话"大哥大"与最新款流线型智能手表的外观演变视频。

[ QUESTION ]

科技不仅是冰冷的代码和电路，我们需要用极客美学为产品赋予灵魂。如何利用工程级软件设计我们的 CarbonBox 发热穿戴外置仓底壳？

INVENTORY

装备与红线

硬件装备

  • 安装有 Fusion 360 的计算机（推荐自带双键鼠标）
  • 游标卡尺
  • ESP32-S3 及电池实体参考件

安全阈值警告

游标卡尺边缘较锐利需防割伤；注意提醒学生随时按 Ctrl+S 键保存于云端项目文件夹以防死机。

EXECUTION PROTOCOL

极客实操步骤

  • 尺寸测绘（10 分钟）：使用游标卡尺测量 ESP32-S3 开发板及 3.7V 电池的真实长宽高尺寸，作为后续壳体设计的内部容积依据，记录在草稿纸上。
  • 软件破冰（15 分钟）：教师带领过一遍 Fusion 360 的视角控制（平移、旋转视角），认识特征树。完成第一次创建"二维草图 -> 拉伸实体"的闭环。
  • 造物理论约束（10 分钟）：教学"壁厚"（通常设 2mm）与"公差"概念（留出 0.5-1mm 余量装配）。
  • 底仓建模实践（15 分钟）：学生独立或在教师带领下创建底壳：新建草图画矩形 -> 拉伸成带厚度的盒子 -> 使用"抽壳"命令掏空内部 -> 底部四边"圆角"处理。

DATA MATRIX

预期数据扫描

全员完成一个长约 60mm，宽约 45mm，高约 20mm，壁厚 2mm 且边缘圆滑的底壳实体 3D 模型。

ARCHITECTURE

反思与物理法则重建

： -

观察结论： 屏幕巡屏展示几位同学刚出炉的模型。

-

底层原理： 指出部分未做倒角模型的"扎手感"和"不易加工性"（直角易翘边），点题"人体工学"。

- 知识建构：数字空间是物理空间的完美前导，先在数字中发现公差干涉问题并在 CAD 里解决，代价最小。

PUSH THE LIMITS

进阶拓展挑战

参数化建模：尝试利用 Fusion 360 的"更改参数"功能，用变量设定长宽，体验修改一个数字，整个外壳瞬间自动重构的神奇参数化工业设计思维。
