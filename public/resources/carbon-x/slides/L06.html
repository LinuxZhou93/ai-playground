OBJECTIVES

核心素养与通关要求

  • 理解（Understand）：理解 FDM（熔融沉积成型）3D 打印技术的原理及切片软件的作用。
  • 2. 应用（Apply）：使用切片软件（如 Cura）将模型转化为 G代码，并操作 3D 打印机输出模型。
  • 3. 评价（Evaluate）：评估第一次打印原型的公差准确性，对出现的问题追根溯源并提出修正方案。

THE HOOK

情境导入

情境再现：展示一个从屏幕中的 3D 模型，到最终拿到手里的实物快进视频（如：钢铁侠战甲分片打印组装）。

[ QUESTION ]

数字模型是一个完美的数学概念，但物理世界存在重力和热胀冷缩。如何让 3D 打印机理解我们的设计并将其实体化？

INVENTORY

装备与红线

硬件装备

  • 已导出 STL 文件的 U盘 或网络传输环境
  • 电脑端切片软件（Cura 或 PrusaSlicer）
  • 3D 打印机（如 拓竹 / 创想三维）及 PLA 耗材
  • 尖嘴钳、砂纸、锉刀等后处理工具

安全阈值警告

打印机喷嘴温度高达实 200℃+，热床 60℃+，运行期间严禁将手伸入打印仓内；使用金属铲铲模型时铲刀必须向外发力远离身体。

EXECUTION PROTOCOL

极客实操步骤

  • 模型降维（15 分钟）：教师讲解切片软件界面。学生导入自己的 STL 模型，设置关键参数：层高（0.2mm）、填充率（通常 15% 即可）、根据悬垂结构决定是否开启支撑（Support）。
  • 切片阵列生成（10 分钟）：预览切片后的打印路径，观察 G-code 代码实际上就是 X/Y/Z 坐标轴运动和挤出指令集。预估打印时间和耗材重量。
  • 上机智造（15 分钟）：各组轮流将文件输入打印机开始打印（因打印时长关系，课堂仅打印核心验证件如底部底仓，其余面盖可延后或作为测试件中断观察）。观察首层附着情况。
  • 模型剥离与后处理（10 分钟）：等待老师打印好的标准原型件分发。学生学习戴耐割手套铲模型、使用水口钳剥除支撑材料以及简单打磨毛边。

DATA MATRIX

预期数据扫描

经历一次从 3D 切片到机器实际加热吐丝成型的完整循环。获得具有一定表面纹理的实体塑料模型。

ARCHITECTURE

反思与物理法则重建

： -

观察结论： 将主控 ESP32-S3 和电池塞入自己打印出的壳体，体验"咔哒"卡入的装配感（或发现干涉塞不进去）。

-

底层原理： 如果塞不进，分析是 CAD 模型公差给少了，还是打印机大平层翘边（大象腿现象）导致底层膨胀。

- 知识建构：意识到原型制作（Prototyping）的第一版往往都会失败，失败再迭代是硬件研发的铁律。

PUSH THE LIMITS

进阶拓展挑战

结构强度暴力测试：采用不同的填充率（如空心 0% vs 高填充 80%）打印出来的同等大小部件，让学生用脚踩或重锤敲击，直观感受力学结构对物理强度的影响。
