[ PRESS SPACE TO INITIATE ]

OBJECTIVES

核心素养与通关要求

  • 理解（Understand）：理解物联网通信中的客户端（Client）与服务端（Server）概念、GATT 协议与蓝牙特征值（Characteristic）。
  • 2. 应用（Apply）：使用 ESP32 开启带指定 UUID 的低功耗蓝牙（BLE）广播。
  • 3. 创造（Create）：利用 Web Bluetooth API，通过网页端建立连接，实时查看碳膜设备的温度并发下控温指令。

THE HOOK

情境导入

情境再现：教师展示苹果手表的健康界面，或是大疆无人机的手机遥控界面，上面飞速跳跃着各种数据。

我们的 CarbonBox 是穿戴在身上的"黑匣子"，并没有自带屏幕和键盘。如果想把它变成真正的 IoT 设备，怎样把碳膜温度、折叠次数等数据传给手机去显示大屏仪表盘？

INVENTORY

装备与红线

硬件装备

  • ESP32-S3 开发板模块
  • 支持 Web Bluetooth 的基于 Chromium 的浏览器（Chrome/Edge 后期版）
  • 现成的 HTML 测试演示网页（教师提供预备模板）

安全阈值警告

开启蓝牙射频后偶尔会有核心发热变大情况；注意修改每个设备的蓝牙命名后缀防止相互串联干扰配对进程（如使用 Carbon_Jack）。

EXECUTION PROTOCOL

极客实操步骤

  • 建立蓝牙广播站（15 分钟）：使用 `BLEDevice::init("Carbon_XX")` 库。讲解服务端、特征属性的设计。配置专属服务 UUID 和包含读写权限的传输通道特征 UUID。并在主循环里每隔一秒通过特征值 `setValue()` 和 `notify()` 推送一个虚拟温度值。
  • 侦听与建立配对（10 分钟）：学生打开电脑浏览器加载提供的 `dashboard.html` 文件，点击页面的"连接设备"，浏览器自动弹出配对搜索框，并在列表内找到自己的那一台 BLE 并确认配对。
  • 数据接发与图表渲染（15 分钟）：打开网页代码，展示 JS（JavaScript）中通过事件监听 `characteristicvaluechanged` 读取发来十六进制字节并解析，驱动网页中的 Echarts 仪表盘指针跳动。
  • 反向下发控制信息（10 分钟）：在网页端放置一个滑动条（Slider）。拉动滑动条，将目标加热温度数值通过 `writeValue()` 逆向发送入主控。主控在回调函数 `onWrite()` 里接收并将内容打印到串口。

DATA MATRIX

预期数据扫描

实现硬软云同频联动：ESP32 推送的数据在网页前端无损展示为图表趋势；网页调配命令能精准回读并在硬件层打印响应动作。

ARCHITECTURE

反思与物理法则重建

： -

观察结论： 分享用网页界面滑动控制板载灯亮度（预演控制碳膜功率）的成就感。

-

底层原理： BLE 摒除了传统经典蓝牙繁琐的握手，以 GATT 这种极其现代的类似键值的读写体系，代表了万物互联最高效的方式。

- 知识建构：硬件只负责出苦力（执行与感知），前端上位机负责华丽界面计算，这就构成了成熟软硬结合系统的前后端分离解耦思维。
