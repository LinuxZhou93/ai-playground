OBJECTIVES

核心素养与通关要求

  • 理解（Understand）：理解从电子元件（散件）、结构外壳到完整原型机（Prototype）的整合封装过程。
  • 2. 应用（Apply）：熟练运用电烙铁、热缩管等工具，在极小空间内完成 3D 打印件与电路的物理拼装。
  • 3. 综合（Synthesize）：合并前三个模块中的发热、传感、蓝牙等离散代码，构成一整套相互协同的系统代码逻辑。

THE HOOK

情境导入

情境再现：老师展示一堆昂贵但凌乱散落的电子零件（主控板、电池、碳膜），然后就像变魔术一样拿出一个最终拼装好的酷炫发热护腕（CarbonBox v1.0 Alpha）。

[ QUESTION ]

在实验室里面包板上跑通功能只是玩具，我们将面临把这些脆弱的连接转化成经得起振动、穿戴的工业级产品的"至暗时刻"。如何进行物理封装与代码缝合？

INVENTORY

装备与红线

硬件装备

  • M2 沉头螺丝与对应螺丝刀
  • 电烙铁套装（含焊锡、松香、海绵）
  • 热缩管（多尺寸）与打火机（教师控制）
  • 3D 打印好的上下壳体组件（L06 产出）
  • 导电铜箔、特种导电碳膜与魔术贴绑带

安全阈值警告

电烙铁尖端处于 350℃ 极高危状态，绝对不能用手触摸金属杆任何部位！注意焊锡飞溅和防烟通风。绝不在通电状态下进行线路拔插更改。

EXECUTION PROTOCOL

极客实操步骤

  • 去面包板化（15 分钟）：教师讲解电烙铁使用安全与上锡技巧。学生开始把杜邦线剪断，剥线，并将其和电阻等元器件直接、紧凑地焊接到主控板孔位与 MOS 模块间。焊接点套上热缩管进行物理绝缘包裹。
  • 硬件装配塞入（15 分钟）：将主控板与电池分别置入 3D 打印仓位，上好底部四个 M2 固定螺丝。把连接端子穿过侧壁布线槽口，用铜箔胶带将碳膜牢牢粘接。
  • 代码大一统（10 分钟）：提供一个框架模板，指导学生将温控发热代码、ADC 曲率识别代码和 Web 通信代码拼合在同一个 `.ino` 文件中，并解决不同模块间延时阻塞（如禁用过度使用 `delay` 导致的系统卡顿，改用 `millis` 定时）造成的逻辑冲突问题。
  • 烤机测试初体验（10 分钟）：连上蓝牙前端，带上护具。开启连续 10 分钟的高压满负荷输出（设定最高安全温标 45℃），体验真实穿戴感。

DATA MATRIX

预期数据扫描

装配完成一个没有裸露走线，能在摇晃中保持不掉电的固体盒子原件。通过蓝牙不仅能调节热量，碳膜本身也能感应手臂弯曲度并把信号发给面板。

ARCHITECTURE

反思与物理法则重建

： -

观察结论： 戴着自己制作好的 CarbonBox 原型机在教室里走动展示。

-

底层原理： 总装时一定会有同学遭遇"装上去灯不亮了"（虚焊/短路）的情况，这就是从理论到实际最大的坑缝工程。成功点亮第一代机器是极其了不起的跨越。

- 知识建构：我们现在有了最小可行性产品（MVP：Minimum Viable Product），接下来的任务就是尽力"弄坏它"，以求寻找它的弱点来改进。

PUSH THE LIMITS

进阶拓展挑战

抗疲劳四小时大考：设定一个"拉力极限"，课后要求学生开启其满负荷通电运行状态并人为不断弯折碳膜并静置数小时，观察温度能否依然稳定在数值阈值之内，外壳有没有因为热量变形软化。
