OBJECTIVES

核心素养与通关要求

  • 理解（Understand）：理解 RGB 全彩 LED 原理及可寻址光带（WS2812）单总线通信机制。
  • 2. 应用（Apply）：调用 FastLED 或 Adafruit_NeoPixel 库，实现多色彩渐变及跑马灯效果控制。
  • 3. 创造（Create）：编写代码实现灯效与碳膜发热功率及系统温度数据的视觉绑定映射。

THE HOOK

情境导入

情境再现：教师展示雷蛇（Razer）外设或是 RGB 幻彩机箱流光溢彩的效果。同样一个键盘，加上幻彩立刻能产生情绪价值变身昂贵电竞外设。

[ QUESTION ]

如何让处于静默发热状态中的碳膜在视觉上"活"过来？让它不是一个无声的黑块，而是可以通过颜色变化传达情绪、显示实时温度状态的高端智能潮玩？

INVENTORY

装备与红线

硬件装备

  • CarbonBox 原型机
  • WS2812（NeoPixel）可编程灯带（一条含 5-8 颗灯珠）
  • FastLED 库
  • 热熔胶枪

安全阈值警告

多颗 WS2812 灯珠在满白光运作时会抽取庞大的主控板电流，若开发板通过电脑 USB 供电可能会被拉低导致不断重启死机，需做好功率计算或独立供电。

EXECUTION PROTOCOL

极客实操步骤

  • 点阵接入（15 分钟）：将 WS2812 灯带连接。其特点只需三根线（VCC 接 3.3V/5V，GND 归地，DIN 数据输入端接 ESP32 任意空闲数字引脚）。用热熔胶沿盒子的四周边缘环绕粘贴一圈。
  • 点亮幻彩（15 分钟）：引入 `Adafruit_NeoPixel` 库。讲解 RGB 色彩模型。通过 `setPixelColor(i, R, G, B)` 函数，学习如何单独控制灯带上任意一颗灯泡亮出任意彩色，然后写一个简单的追逐流水灯光效体验一下。
  • 数据光影映射（20 分钟）：这是本节课真正的亮点——将冷冰冰数据具象化。重构主函数代码逻辑：利用 `map()` 函数，将 ADC 测得的温度值（如 25℃-45℃），映射成为颜色（从冷蓝色 `0,0,255` 渐变到火红色 `255,0,0`），从而让灯效变为一个真实的"温度计光效外壳"。

DATA MATRIX

预期数据扫描

当碳膜不工作时，灯带呈现幽蓝的呼吸态；开始加热即向暖色彩过渡，在满载达最高温时散发强烈的红光并进行高频爆闪警告。

ARCHITECTURE

反思与物理法则重建

： -

观察结论： 将关掉教室大灯，全班展示各自不同映射逻辑的呼吸、爆闪或随碳膜按压渐变的光污染效果。

-

底层原理： 色彩的暗示是一种心理学行为设计。红色预警，蓝色待机。在无屏设备上，这就是最重要的且直击心智的 GUI（图形用户界面）。

- 知识建构：我们融合了物质（发热碳膜）、能量（调压电路）、数据（传感器反馈）、视觉（多色光影）。系统级产品逐渐成型了。

PUSH THE LIMITS

进阶拓展挑战

双驱连携响应：尝试同时引入两种变量：当温度升高时改变颜色色相，当用户揉捏扭曲碳膜施加压力时（形变压阻变化）则改变灯效的闪烁频率（心跳震荡律动）。
