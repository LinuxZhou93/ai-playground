CHAPTER 01:
VECTOR SPACE TOPOLOGY

记忆在我们的维度里是一个几何问题。每一个 Chunk（文本块）都会被 **Gemini-v2-Embedding** 映射为一个 1536 维的向量。

HNSW GRAPH LOGIC

我们使用‘分层导航小世界 (Hierarchical Navigable Small Worlds)’算法。这就像在高山、丘陵和平原之间建立了分级高速公路。AI 可以先在宏观层级快速定位，然后逐层下降，最终在亿万数据中精准定位到具体坐标。

COSINE SIMILARITY

测量两个想法之间的距离，不是直线长度，而是角度。通过计算张角余弦值，我们能识别出即便字面上完全不相关的‘概念共振’。

DIST = Σ(Ai * Bi) / (||A|| * ||B||) DIM = 1536 (FP32) M = 16 (HNSW) EF_CONS = 200

CHAPTER 03:
MEMORY CONSOLIDATION

如果记忆发生了冲突怎么办？

在 OpenClaw 系统的‘休眠期’，我们会运行知识合流层 (Consolidation Layer)。系统会扫描那些极其相似的、存在冗余或旧版本的知识节点。

THE MERGING SPIRIT

过时的信息会被标记为‘沉睡文档’并降权存储。核心事实会被提取为更简洁的语义摘要，合并入‘中央知识图谱’。这让 AI 的大脑随着实验的增加，不仅不会膨胀，反而会变得更锐利。

CONFLICT RESOLUTION

当 A 实验记录与 B 实验记录在数据上发生矛盾时，系统会自动启动‘回归验证 Agent’。它会通过 Search 和 Code Skill 重新运行测试逻辑，决定哪个版本才是最终真理。
