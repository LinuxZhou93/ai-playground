Python 极速赛车

这是一个基于 Python Tkinter 开发的复古风格赛车游戏。虽然它不能直接在浏览器中运行，但你可以下载源码在本地体验！

🎮 游戏玩法

  • 使用 方向键 或 A/D 控制赛车左右移动
  • 躲避不断加速下落的红色障碍物
  • 按 空格键 重新开始，ESC 退出

🚀 如何运行

1. 确保你的电脑已安装 Python。

2. 下载源代码文件。

3. 在终端中运行以下命令：

python racing_game.py
