# 西马棚幼儿园儿童原画卡通化生成规范

运行模式：GPT Image 2 Skill Mode B（宿主有图像工具；项目本身通过服务端模型网关执行图像编辑）。

## 输入

- 一张俯拍 A4 儿童原画，不是人物照片。
- 原画可能使用水彩笔、蜡笔、马克笔或铅笔。
- 只对画作内容生成，不识别作者，不生成人像。

## 统一风格

最终成品必须明显属于高品质儿童动画或现代童书绘本，而不是照片。保留原画关键主体的不规则轮廓、颜色关系、朝向、比例、儿童笔触和可爱的不完美，让这些真实笔触继续留在主角表面。

使用圆润造型、明亮色块、柔和描边、toon shading、卡通体积光、温暖景深、可爱动作与适度夸张。允许“高级 3D 动画 + 水彩绘本纹理”融合，但不要把原画主角重画成标准商业 IP。

## 四个固定配方

1. 化形万物：原画角色进入与其匹配的卡通动画家园并自然活动。
2. 奇物成真：原画物体变成卡通软陶、毛绒玩具或动画装置。
3. 画境生长：沿原画空间关系扩展成童话绘本世界。
4. 童画大片：把原画事件变成卡通动画电影关键帧，而不是真人电影剧照。

## 必须避免

- 照片级写实、超写实摄影、真人电影剧照。
- 真实儿童或成人面孔、真实皮肤毛孔、写实动物皮毛。
- 写实商品渲染、阴暗恐怖、成人冷峻审美。
- 把原画主体替换成统一模板角色或商业 IP。
- 把成品退化成单薄简笔画、廉价扁平图标、游戏 UI、贴纸、相框或文字海报。

## 输出

- 16:9 横向。
- 3–6 岁儿童友好。
- 喜悦、惊奇、明亮、安全。
- 主角只出现一次，无恐怖与危险元素。
