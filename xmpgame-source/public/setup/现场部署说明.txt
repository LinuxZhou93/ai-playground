西马棚幼儿园 XMPGame 四台触屏一体机部署包
==========================================

推荐方式：U盘逐台安装（每台约 1 分钟）

准备：
1. 把 setup 文件夹或 xmpgame-kiosk-usb.zip 解压后的全部文件放进U盘。
2. 四台电脑要能上网，并且已经安装 Microsoft Edge。
3. 四台电脑要有 Python 3。现场机器桌面已有 Python 图标时通常已经满足。
4. Windows 开机后需要自动进入当前桌面账号；浏览器界面无法在未登录账号时显示。

逐台安装：
- 1号机（化形万物）：双击 install-station-1.cmd
- 2号机（奇物成真）：双击 install-station-2.cmd
- 3号机（画境生长）：双击 install-station-3.cmd
- 4号机（童画大片）：双击 install-station-4.cmd

出现 Windows 管理员确认窗口时点“是”。安装完成后会立刻打开对应项目。

验收：
1. 点一次页面右上角“全屏体验”。
2. 检查俯拍摄像头画面和触摸操作。
3. 重启电脑；进入桌面约 15～30 秒后，应自动打开对应项目的全屏页面。
4. 断开再恢复网络，页面仍应自动重试；浏览器意外关闭后约 4 秒会重新打开。

每台固定网址：
1号机 https://www.zhouxiaomai.com/xmpgame/station/1?kiosk=1
2号机 https://www.zhouxiaomai.com/xmpgame/station/2?kiosk=1
3号机 https://www.zhouxiaomai.com/xmpgame/station/3?kiosk=1
4号机 https://www.zhouxiaomai.com/xmpgame/station/4?kiosk=1

检查与维护：
- 双击 check-installation.cmd 查看本机项目、网址、浏览器和开机任务状态。
- 日志在 C:\ProgramData\XMPGame\xmpgame-kiosk.log。
- 需要取消开机自启动时，双击 uninstall-xmpgame-kiosk.cmd。
- 安装程序会清理本项目旧版开机快捷方式，防止浏览器重复启动；不会删除其他程序。

如果机器没有 Python：
- 可以使用现有 install-xmpgame-autostart.ps1；或者先安装 Python 3 后再运行上述安装文件。
- 正式现场建议保留同一U盘，作为四台设备的维修包。
